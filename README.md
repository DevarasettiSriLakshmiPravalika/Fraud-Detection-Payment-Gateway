# Fraud Detection Payment Gateway (FDPG)

## Brief Description
A modern payment gateway with integrated fraud detection and risk scoring capabilities. Designed as a modular monolith to provide clear separation of concerns while maintaining deployment simplicity.

## Current Project Status
Phase 1 completed

### Backend Architecture
- Converted from microservices to a clean Modular Monolith structure.
- Organized into modules: common, auth, payment, risk, notification, admin.
- Standardized API response format and global exception handling.

### Frontend Architecture
- Cleaned up folder structure for maintainability.
- Added directories for components, pages, layouts, services, hooks, context, utils, styles, and assets.
